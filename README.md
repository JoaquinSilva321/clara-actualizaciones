# Clara

Tu dinero, con datos locales. Este repositorio distribuye las APK y la información de actualización; no almacena movimientos, comprobantes ni copias de seguridad de sus usuarios.

[Descargar la última versión](https://github.com/JoaquinSilva321/clara-actualizaciones/releases/latest)

## Instalación

La APK universal requiere Android 8 o posterior e incluye ARM de 32 y 64 bits. Las funciones opcionales tienen requisitos adicionales del teléfono.

Instalá sobre Clara, **sin desinstalar**, para conservar tus datos. Android solicita confirmar la instalación y puede pedir permitir esta fuente. La primera versión con el actualizador se instala manualmente.

## Actualizaciones

En **Más → Ajustes → Actualizaciones** podés buscar una versión, revisar las novedades y elegir si querés descargarla. Las comprobaciones automáticas son opcionales; nunca descargan ni instalan por su cuenta. Android confirma cada instalación.

La gestión del dinero, los documentos y sus cálculos permanecen en el teléfono. El actualizador consulta este canal público de GitHub; no sube los datos financieros. Sin conexión podés seguir usando Clara.

Cada publicación incluye la APK, `version.json` y la suma SHA-256. No se necesita una cuenta de GitHub para descargarlos.
